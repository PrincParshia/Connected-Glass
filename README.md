## 📘 DESCRIPTION

This is a sleek add-on for Minecraft, making glass textures seamlessly connect for a cleaner, more modern look. This pack keeps the default style of Minecraft while enhancing the appearance of glass blocks and panes, giving your builds a polished, uninterrupted feel.

## ❗ REQUIREMENTS

* For **Fabric/Quilt/Neo/Forge**: Use **[Continuity](https://modrinth.com/mod/continuity)**.

* For **Forge/Other**: Use **[OptiFine](https://optifine.net/home)**.
